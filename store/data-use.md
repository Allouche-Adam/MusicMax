# Data usage disclosure answers

Developer Dashboard → **Privacy practices** → "What user data do you plan to collect
from users now or in the future?"

SpotiPlus sends the playing song's **title, artist and length** to a lyrics service
(LRCLIB; plus Genius and NetEase if the user turned them on) to find lyrics. Nothing
reaches the developer: there is no server, account, analytics or ads.

The song being played is read from the page, so the honest box to tick is
**Website content**. Leave everything else unticked.

| Category | Answer | Why |
| --- | --- | --- |
| Personally identifiable information | No | No name, email, address or ID is read or sent. |
| Health information | No | |
| Financial and payment information | No | |
| Authentication information | No | Never reads passwords or Spotify login data. |
| Personal communications | No | |
| Location | No | |
| Web history | No | Runs only on open.spotify.com; no list of visited pages is collected. |
| User activity | No | No clicks, keystrokes or listening history leave the device. |
| Website content | **Yes** | The song title, artist and length shown on the page are sent to the lyrics service, only to fetch that song's lyrics. Not stored by the developer. |
